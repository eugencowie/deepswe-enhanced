# Spec: Model data

Replaces the leaderboard model ids in the [leaderboard table](../leaderboard-table/spec.md)'s Model cell with display names and vendor marks, neither of which DeepSWE's data files provide, and owns the model mapping file. Vocabulary: display name, vendor, vendor mark, model mapping in [docs/context.md](../../context.md).

## Data file: `data/model-mapping.json`

One entry per leaderboard model (effort levels share it), written by hand or generated by the refresh for known vendors ([ADR 0003](../../architecture/0003-refresh-generates-mapping-entries.md)); either way entries land through PR review. `displayName` follows the OpenRouter-derived form (listing name minus the vendor prefix and any revision token); `vendor` is copied from same-vendor entries, never from OpenRouter's author strings. Entry shape: `{ "leaderboardModel": string, "displayName": string, "vendor": string, "openrouterId": string | null, "family": "claude" | "chatgpt" | "none", "usageMultiplier": number, "excludedTiers"?: TierId[], "shortName"?: string }`. The `openrouterId` field is specified by [average time data](../avg-time-data/spec.md), `family`, `usageMultiplier` and `excludedTiers` by [subscription data](../subscription-data/spec.md), and `shortName` by [subscription filter](../subscription-filter/spec.md). A leaderboard model missing from the mapping makes derive throw, and a unit test enforces full coverage — the failure surfaces through `vp run validate` and CI (don't silently drop rows).

## App

- The Model cell shows the mapping `displayName` in place of the leaderboard model id. It carries a tooltip with the mapped OpenRouter id, since display names omit revisions. It also leads with the vendor mark (see [vendor mark research](../product-spec/research/vendor-marks.md) and [ticket 01](tickets/01-vendor-marks.md)): a small inline SVG from `@lobehub/icons-static-svg`, `aria-label`led with the vendor name, monochrome marks following the theme via `currentColor`.

## Acceptance criteria

- Every leaderboard model renders with its display name and vendor mark; a model missing from the mapping fails `vp run validate` rather than rendering without one.
